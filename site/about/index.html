About KAMBIODEX

KAMBIODEX is a decentralized exchange (DEX) on the Polygon network. You swap tokens straight from your own wallet, and anyone can earn trading fees by providing liquidity to a pool. We never hold your funds.

What it does

KAMBIODEX is built on the concentrated-liquidity model of Uniswap v3. Liquidity providers choose a price range, and each position is an NFT (KAMBIODEX V3 Positions, symbol KBX-V3-POS). Swaps are routed on-chain by the SwapRouter contract and settle directly between wallets and pools.

Open source and transparency

The contracts are a modified fork of Uniswap v3 (core and periphery), released as GPL-2.0-or-later with MIT components; the original licence headers are kept and listed in the NOTICE file of the repository. Every change we made is listed in the CHANGES file of the public repository, and the position-NFT descriptor was written from scratch. The upstream Uniswap v3 code has been publicly audited; KAMBIODEX has not yet had its own third-party audit, and we say so openly. Our security plan and the deployment records are in the repository.

The interface keeps all trading data on-chain. Token lists use trust levels, and only tokens approved one by one are shown as trusted. Always check a token address before you trade.

Team

KAMBIODEX is built and operated by a small, independent core team that works under the name “KAMBIODEX Team”. The team is pseudonymous: accountability does not rest on personal profiles but on what anyone can verify — public source code, open-source licences, official contracts that anyone can inspect on Polygonscan, and protocol settings controlled by a hardware-wallet address (listed above) instead of a single software key.

For questions, partnerships or security reports, write to kambiodex@kambiodex.com.

Risks

Using a DEX involves risk, including smart-contract bugs, price volatility and impermanent loss for liquidity providers. Nothing on this site is financial advice.
