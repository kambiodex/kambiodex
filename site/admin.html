Pedidos para a Safe

Nada foi enviado. Baixe o arquivo, abra a Safe → Apps → Transaction Builder → arraste o arquivo, confira cada linha (endereço de destino e função) e assine com os outros assinantes. Você só deve assinar se o destino e a ação forem exatamente os listados aqui.

Registro de tokens: posse

Se o Registro foi passado para a Safe em duas etapas, a Safe precisa aceitar a posse. Este botão gera o pedido acceptOwnership().

Valores fixos: Ligar = setFeeProtocol(6, 6) (1/6 para o protocolo e 5/6 para quem colocou liquidez); Desligar = setFeeProtocol(0, 0). O que já acumulou continua disponível para coletar. A coleta envia sempre para a carteira conectada (que precisa ser a dona). Nenhuma chave passa por esta página: quem assina é a sua carteira (MetaMask).
